# CASE-0010｜Historic Centre of Macao：澳门历史城区编年与遗产地标目录

- 主题：澳门历史城区的历史节点、遗产建筑、历史空间、地理分布与城市风貌

- 核心结构：左侧历史时间节点＋中央建筑地标图像目录＋右侧空间地图／补充专题＋底部城市色彩与形态信息

## 分类理由
图面以澳门历史城区为统一主题，中央区域集中展示多组具有代表性的历史建筑、遗产空间和建筑群，并通过引线、名称与说明文字构成建筑／场所目录。右上角地图显示历史城区在城市中的空间位置，右侧还设置建筑剖面／街景、关系分支和城市色彩等辅助专题。

左侧纵向历史节点带提供年代、历史事件和时间提示，是重要的编年信息模块；但图面并非单一时间轴：中央主体并未严格按时间逐项排列，更多是将遗产对象按空间、类别或版面关系组合呈现。因此主逻辑判为编目型，编年型为辅助；地图承担地理定位和空间分布的辅助功能。

## 图面可确认的模块
1. 标题与导语：中英文标题“澳门历史城区 / Historic Centre of Macao”，下方为中文介绍性文字。
2. 左侧历史时间线：按图面纵向列出多个历史年份和时期标识，包含明、清及新中国等分期文字；节点以不同颜色、大小和形状区分。
3. 中央遗产建筑群：以彩色建筑立面、街区、台阶、树木、铺地和场地插画组成大型建筑／场所图像目录，并用引线和文字标注。
4. 右上地理地图：以城市道路底图为背景，使用色块标记历史城区相关空间；旁边配有图例／文字说明。
5. 右侧建筑与空间专题：包含建筑横向立面／场景图及其文字说明。
6. 右下关系分支图：以节点和分支连接若干空间／类别标签，具体术语在当前分辨率下不完全可辨。
7. 右下城市色彩模块：以多列竖向色块组合展示澳门城市／建筑色彩特征。
8. 左下图例：以不同图标和符号列出遗产对象或空间类型；部分文字过小，需原始高清图核对。

## 重要数据限制
- 左侧时间线的部分事件说明文字无法从当前900 × 1200 px图像中可靠辨认，因此只录入可确认的年份／时期，不补写事件名称。

- 右上地图的边界、色块图例及精确范围需要高清原图或原始出版物核对。
- 右下关系分支图的节点文字、左下图例文字和城市色彩图例未能完整辨认。
- 本案例属于图面结构分析与可辨文字转录，不代表已经完成澳门历史事实、遗产名录或建筑身份的独立核验。
