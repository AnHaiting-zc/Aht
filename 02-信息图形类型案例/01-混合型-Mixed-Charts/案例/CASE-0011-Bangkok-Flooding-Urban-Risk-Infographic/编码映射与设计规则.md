# 编码映射与设计规则｜CASE-0011

## 1. 版式骨架
- 纵向海报，顶部大标题。
- 左右两侧安排统计图表、数字卡和说明段落。
- 中央安排城市天际线、云雨、弯曲水道／道路式场景和车辆插画。
- 右上设置灾害受影响人数比较和评分徽章。
- 左侧中下设置城市脆弱性和排水系统专题。
- 右下设置2011年洪灾损失、现场照片和柱状图。
- 底部横排资料来源。

## 2. 色彩编码
| 色彩组 | 可见用途 | 编码边界 |
|---|---|---|
| 深海军蓝／藏青 | 主标题、建筑轮廓、河道、重要数字 | 主视觉骨架，不代表单一风险等级 |
| 青蓝／湖蓝 | 水体、图表柱体、城市信息 | 主题关联和模块识别 |
| 珊瑚粉／鲑橙 | 场景底形、边界强调、重点数字 | 警示与强调，不等于数值正负 |
| 浅青白／淡蓝灰 | 背景、卡片、留白 | 提高文字与图表可读性 |
| 少量绿色 | 个别图标与标签 | 辅助强调，具体语义待核 |

## 3. 图形语法
| 元素 | 角色 | 信息功能 |
|---|---|---|
| 月度柱状图 | 季节背景 | 展示月份序列数值 |
| 虚线趋势 | 变化提示 | 与柱状序列共同表达变化 |
| 圆形气泡 | 灾害类别比较 | 受影响人数对比 |
| 风险徽章 | 指标卡片 | 显示评分，项目名称需核 |
| 大号数字 | 关键指标 | 快速传达风险和损失 |
| 圆角标签 | 图文注释 | 将数值与短说明绑定 |
| 中央城市插画 | 叙事锚点 | 统一城市空间情境 |
| 引线 | 对象关联 | 将风险因素锚定到建筑／环境位置 |
| 圆形照片 | 现场证据 | 提供灾害与城市实景补充 |
| 右下柱状图 | 时间／类别序列 | 标题和单位待核 |
| 来源编号 | 资料提示 | 标示参考资料，但需补足逐项映射 |

## 4. 中央场景插画规则
- 建筑采用高层正立面和简化透视，形成曼谷城市天际线。
- 云朵、雨滴和水体符号直接建立洪涝与季风语境。
- 深蓝弯曲形态从中央向底部延伸，边缘用珊瑚色强调。
- 照片以圆形裁切嵌入插画场景，作为现实影像证据。
- 车辆和底部水面补充城市交通与洪水影响的情境。
- 场景用于主题叙事，不应读取为比例准确的地图或水动力模拟。

## 5. 信息层级
1. FLOODING主标题；
2. 副标题与导语；
3. 中央城市场景；
4. 右上灾害人数与评分；
5. 左侧大数字和排水系统专题；
6. 右下2011年损失和柱状图；
7. 小字解释与来源列表。

## 6. 可迁移设计规则
1. 以城市场景插画作为灾害主题的视觉锚点。
2. 将背景、影响、成因、基础设施和历史损失拆分为独立专题。
3. 不同数据类型使用适合的图表，但保持统一卡片、标题、线宽和色彩规范。
4. 每个关键数字都应标明单位、统计期、空间范围和来源。
5. 风险评分必须给出指标定义、量表方向和评分方法。
6. 气泡面积若表达数量，应提供明确比例图例。
7. 地理场景插画和精确地图应使用不同视觉语法。
8. 现场照片应有拍摄时间、地点、摄影者或来源。
9. 对预测数字标注情景假设和不确定性。
10. 建立来源编号到具体指标的映射表。
