# 混合型图表（Mixed Charts）案例库

本目录收录在同一数据叙事中组合两种或以上数据图表／可视化形式的案例。

## 标签说明
- [混合型图表定义与判定方法](./00-标签说明.md)

## 案例
- [CASE-0011｜FLOODING：曼谷洪涝危机与城市韧性信息图](./CASE-0011-Bangkok-Flooding-Urban-Risk-Infographic/README.md)：季风降雨、灾害影响、城市洪涝成因、排水系统短板与2011年洪灾损失组合多种图表和城市场景插画。
- [CASE-0009｜Lima Urban Environmental Systems：利马城市环境系统](./CASE-0009-Lima-Urban-Environmental-Systems/README.md)：空气、绿地、污水与固废四个专题组合比例图、饼图、数值图、地图和处理量关系图，属于多种数据可视化形式共同服务于同一城市环境叙事的混合型图表案例。
