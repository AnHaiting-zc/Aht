# 数据字典｜CASE-0009

## 数据集.csv字段

| 字段 | 类型 | 含义 |
|---|---|---|
| case_id | string | 案例编号 |
| domain | string | 环境专题：AIRE、ÁREAS VERDES、AGUA、RESIDUOS |
| indicator_name | string | 图面指标名称或简要释义 |
| displayed_value | string/number | 图面显示数值；范围值及“大于”值保留文本表达 |
| unit | string | 图面单位；未注明时明确写出 |
| comparison_or_denominator | string | 分母、比较对象或图面口径 |
| geography | string | 城市、行政区、道路或河流等空间对象 |
| reference_year | string | 数据年份；当前图面未注明，留空 |
| source_as_shown | string | 图面可见来源文字 |
| evidence_status | string | 图面转录／待核验 |
| ambiguity_note | string | 单位、口径、图例或语义不确定事项 |

## 证据等级
- 图面转录：能够从上传图片辨认的文字、数字和单位。
- 结构推断：依据图形位置、箭头或版式推断的关系，必须在分析中说明。
- 待核验：图面未提供足够信息确认年份、分母、来源版本、定义或空间映射。

## 重要数据约束
1. 图面没有统一参考年份，reference_year不填造。
2. “7 mil toneladas”未注明时间单位，不得转换为吨／日或吨／年。
3. “20.000 litros por segundo”按西班牙语常用千位分隔方式录为20,000 L/s；仍需核对原始来源。
4. 绿地的3,207、2,700和244公顷关系不清，分别保留。
5. 水模块20,000、3,200和1,000 L/s分别记录，不假设同一分母。
6. 图面所称80%未经处理水由“Agua sin tratamiento”文字直接支持；20%已处理水是饼图互补部分。
7. 固废地图的45%—85%为范围，不能据此推算各行政区的具体值。
8. 地图上的颜色或符号若没有图例，不赋予未经证实的量化含义。
