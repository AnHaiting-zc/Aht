# 数据字典｜CASE-0011

## 数据集.csv字段

| 字段 | 类型 | 含义 |
|---|---|---|
| case_id | string | 案例编号 |
| module_id | string | 对应视觉模块编号 |
| indicator_name | string | 图面指标名称或保守描述 |
| displayed_value | string/number | 图面可见数值，范围和模糊单位保留原表达 |
| unit | string | 图面可辨单位；未注明时写明 |
| period | string | 统计年份、月份或时间范围；缺失时标注未注明 |
| geography | string | 城市、国家或图面所述空间范围 |
| definition_or_denominator | string | 指标定义、分母或比较对象 |
| source_as_shown | string | 图面可见来源文字 |
| evidence_status | string | 图面转录／结构推断／待核验 |
| ambiguity_note | string | 口径、标签、单位或图例不确定事项 |

## 视觉模块.csv字段
| 字段 | 含义 |
|---|---|
| case_id | 案例编号 |
| module_id | 模块编号 |
| order | 视觉阅读顺序 |
| zone | 版面位置 |
| module_content | 模块内容 |
| information_role | 信息功能 |
| visual_form | 图表或插画形式 |
| visual_encoding | 可见视觉编码 |
| limitations | 模块识读限制 |

## 证据等级
- **图面转录**：能够从上传图像辨认的文字、数字和单位。
- **结构推断**：根据模块位置、图形关系和注释组织推断其信息功能；必须说明推断性质。
- **待核验**：标签、分母、年份、定义、比例规则或来源版本无法从当前图像确认。

## 数据边界
1. 不把中央11.07 Million、2nd、3% Annual猜测为人口、排名或降雨指标。
2. 灾害人数只按图面可见类别和数值记录，不补写统计年份和地理范围。
3. 风险评分只记录分值，不猜测评分项目和量表方向。
4. “<15 years”只保留图面表达，不推断具体后果或预测起点。
5. 200 m³/min与2,000 m³/min分别记录，不擅自计算实际缺口比例。
6. 2011年洪灾四个附加数字不猜测其对应的死亡、受灾、经济或设施类别。
7. 底部柱状图不补写标题、单位和数值。
8. 中央弯曲场景不作为精确地理地图、河道测绘或洪水模型。
9. 图片来源列表不等于每项指标均已被对应来源证实。
