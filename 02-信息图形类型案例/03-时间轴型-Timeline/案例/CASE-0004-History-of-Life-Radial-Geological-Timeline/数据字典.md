# 数据字典｜CASE-0004

本案例的数据仅从用户提供的局部裁切图中转录，不代表已核验原始数据源。

| 字段 | 类型 | 含义 | 单位／取值 | 说明 |
|---|---|---|---|---|
| case_id | string | 案例编号 | CASE-0004 | 仓库内部编号 |
| record_type | string | 记录类型 | age_marker / geological_interval / event_category | 区分年代标记、地质时期与事件类别 |
| label | string | 图面标签 | 英文原文 | 逐字转录可辨文字 |
| age_million_years | integer | 年代标记 | Ma（百万年） | 仅填入图面可见数字 |
| unit | string | 时间单位 | Ma | 图例为Millions of years |
| visual_encoding | string | 视觉表达 | 虚线／红色事件符号等 | 仅描述图面可见形式 |
| transcription_status | string | 转录状态 | Visible / Legend visible | 标明文字或图例是否可见 |
| notes | string | 限制说明 | 自由文本 | 记录边界不确定、事件名称不可辨等问题 |

## 重要限制

- 可见年代数字：4600、4000、2500、542、488、443、416、374、359。
- 可见时期名称：Hadean、Archean、Proterozoic、Cambrian、Ordovician、Silurian、Devonian。
- 左侧还有被裁切的时期标签，不强行补全。
- 不推断各数字与具体时期的完整边界对应关系。
- 不将图示事件符号擅自映射到具体大灭绝事件名称。
- 不把径向扇环的角度、宽度或面积解释为统计比例。
