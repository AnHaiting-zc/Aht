# 04｜示意图型／How-to Infographics

## 1. 类型定义
示意图型／How-to信息图以解释某个对象如何操作、某项任务如何完成或某个机制如何使用为核心。通常使用动作插画、局部结构、编号说明、工具和操作文字帮助读者模仿或理解。

## 2. 核心表达
- 操作对象：被处理或使用的对象；
- 动作：具体执行的操作；
- 工具：完成动作所需的器具；
- 操作提示：步骤说明、注意事项；
- 结果：操作后的状态或产物。

## 3. 与流程图型的区别
- How-to侧重“动作怎么做”，重视操作细节和图文示范。
- Process侧重“步骤如何衔接”，重视顺序、依赖、分支和状态变化。
- 同一案例可以同时具有How-to和Process特征；应按全图主叙事选择主分类，并用交叉标签记录另一种特征。

## 4. 视觉形式
- 动作人物／手部插画；
- 工具与对象的局部示意；
- 编号步骤与短句说明；
- 分解图、局部放大和前后状态对照；
- 连续路径或阶段式版面。

## 5. 质量控制
- 图示动作应与文字说明一致；
- 工具、材料和操作对象应能清楚识别；
- 关键安全提示或工艺前置条件不可省略；
- 若存在严格操作顺序，应与流程图逻辑一致。
