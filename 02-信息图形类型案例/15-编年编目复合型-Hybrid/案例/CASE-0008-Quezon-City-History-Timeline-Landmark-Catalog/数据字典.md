# 数据字典｜CASE-0008

## 1. 历史条目.csv
| 字段 | 类型 | 含义 |
|---|---|---|
| case_id | string | 案例编号 |
| entry_id | string | 条目唯一标识 |
| visible_order | integer | 图面从上至下的显示顺序，不等于年代顺序 |
| visible_year | string | 图面年份原样转录 |
| normalized_year | integer/string | 可规范化年份；不代表已核验史实 |
| entry_title | string | 图面条目标题 |
| entry_category | string | 对象／事件的初步类别 |
| visible_description_summary | string | 图面说明摘要 |
| related_person_or_entity | string | 图面提及人物或机构 |
| place_label | string | 图面可辨地点 |
| image_subject | string | 配图可见主题 |
| time_semantics | string | 年份可能代表的时间含义；不清楚时标注待核验 |
| confidence | enum | 图面转录可信度，不等于历史真实性 |
| verification_notes | string | 事实核验事项 |

## 2. 视觉模块.csv

## 3. 建议实体关系
- HistoricalEntry 1:1 YearMarker；
- HistoricalEntry 1:N ImageAsset；
- HistoricalEntry 1:1 NarrativeText；
- HistoricalEntry N:M Person；
- HistoricalEntry N:M Place；
- HistoricalEntry N:1 Category。

以上为推荐建模方式。实际录入数据库时，应将条目年份的语义单独标注，例如事件发生、建成年份、迁建年份、纪念设立年份或图面作者选定的历史节点。

## 4. 分类规则
- 编目型：每个历史对象／事件为一条独立记录，可单独阅读。
- 编年型：年份提供时间属性与历史参照。
- 复合标签：编年＋编目。
- 不将visible_order当作chronological_order。
- 若未来经可靠来源核验并重新按年份排序，可另建严格编年版本，但不要覆盖原图面顺序记录。
