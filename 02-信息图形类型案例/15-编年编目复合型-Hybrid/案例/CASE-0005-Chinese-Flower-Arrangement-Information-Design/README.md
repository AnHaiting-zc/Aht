# CASE-0005｜三枝成韵·满室生春：中国插花信息设计

一张围绕中国传统插花知识组织的纵向复合信息图。上半部分呈现发展历史、主要流派与历史时间脉络；下半部分呈现花器、几架、花材形状和花材筛选等分类知识，并以中心插花作品作为主视觉。

## 分类
- 市场表现主标签：15-编年编目复合型（Hybrid）
- 五大基础逻辑：编目型为主，编年型和地理图型为重要辅助；局部包含层级分类与关系流向表达。
- 交叉标签：混合信息图、时间轴、地图、分类树、关系流线图、主题插画。
