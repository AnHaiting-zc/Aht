# CASE-0013｜Government Secret Clearance Levels：政府机密许可等级层级信息图

- 图片尺寸：768 × 1344 px；归档依据：用户于2026-11-26上传图像。
- 主分类：层级型（Hierarchical）。
- 辅助逻辑：比较型（Comparison Snapshot）；流程型（Clearance Process Journey）。
- 表现形式：四级立体漏斗／层级体＋等级说明＋比较矩阵＋六阶段流程带。

## 类型判定
中央四层倒梯形体由上至下排列Top Secret、Secret、Confidential、Unclassified，形成明确的等级顺序；右侧解释各级信息敏感程度和示例。层级关系是全图核心。左下矩阵比较四级在信息访问、调查深度、复核频率、信息敏感性上的相对差异；底部流程带说明申请到持续复评的程序。因此唯一主分类为层级型，比较与流程作为辅助标签，不重复归档。

## 四级内容
1. **TOP SECRET（TS）**：访问最敏感的机密信息。示例：National security、Intelligence sources、Critical programs。
2. **SECRET（S）**：披露后可能造成严重损害的信息。示例：Military operations、Diplomatic information、Sensitive projects。
3. **CONFIDENTIAL（C）**：披露后可能造成损害的信息。示例：Internal reports、Privacy data、Security procedures。
4. **UNCLASSIFIED（U）**：无需正式许可。示例：Public information、Routine correspondence、General documents。
