# 数据字典｜CASE-0007

## 1. 可见时间标记.csv
| 字段 | 类型 | 含义 |
|---|---|---|
| case_id | string | 案例编号 |
| marker_id | string | 时间标记唯一编号 |
| visible_label | string | 图面原始可见年份／日期 |
| normalized_time | string | 可规范化的时间值；仅对明确日期／年份填写 |
| time_precision | enum | day／year等时间精度 |
| visual_position | string | 时间标记在图面中的位置 |
| event_or_project_label | string | 可辨事件／项目名称；不可辨时留空或注明待核验 |
| confidence | enum | high／medium／low |
| notes | string | 转录限制与说明 |

## 2. 建筑项目观察.csv
| 字段 | 类型 | 含义 |
|---|---|---|
| case_id | string | 案例编号 |
| project_id | string | 项目观察编号 |
| visible_year | string | 图面项目卡片标注年份 |
| visible_project_name | string | 可辨项目名称；不可辨时明确标注 |
| visual_type | string | 建筑照片、立面、模型等图像类型 |
| location | string | 仅在图面明确可辨时填写 |
| confidence | enum | 识别可信度 |
| notes | string | 名称与年份的证据边界 |

## 3. 地理与人物元素.csv
| 字段 | 类型 | 含义 |
|---|---|---|
| case_id | string | 案例编号 |
| element_id | string | 元素唯一编号 |
| element_type | string | geographic_label、map、map_marker、portrait等 |
| visible_label | string | 可见标签／元素名称 |
| visual_role | string | 元素在信息结构中的作用 |
| confidence | enum | 识别可信度 |
| notes | string | 解释边界 |

## 4. 建议关系模型
- Person 1:N Event；
- Event N:1 TimeMarker；
- Project N:1 TimeMarker（仅当图面引线或可靠来源确认对应关系时建立）；
- Project N:1 Place（地点有证据时填写）；
- Person N:M Person（需明确人物身份和关系来源后才建立）；
- Project 1:N ImageAsset。

## 5. 数据边界
- 环形轨道的角度、长度和节点间距不默认代表真实年份间隔。
- 不将地图圆点解释为迁居、任职或项目地点，除非图例或来源确认。
- 不根据小型肖像推断人物姓名、身份或关系。
- 不把建筑图片尺寸、圆点大小、红色描边或文字大小解释为数值。
- 对无法辨认的项目名称保留空缺／待核验，不依据常识补全。
