# 数据字典｜CASE-0005

本案例基于图面结构建立“模块级观察数据”，不是对原图全部文字或底层数据的完整转录。

| 字段 | 类型 | 含义 | 示例／取值 | 说明 |
|---|---|---|---|---|
| case_id | string | 案例编号 | CASE-0005 | 仓库内部编号 |
| zone | string | 版面区域 | upper / lower | 上半版面或下半版面 |
| module | string | 模块机器标识 | history / vessel_catalog | 便于后续检索 |
| visible_title | string | 可辨识模块标题 | 发展历史 | 无法辨认时留空 |
| visual_form | string | 可见图形形式 | 地图、分类树、曲线流线 | 仅描述图面形态 |
| information_logic | string | 信息关系类型 | 编年、编目、地理、层级、关系 | 允许复合 |
| observed_content | string | 可观察内容 | 花器轮廓、历史阶段 | 不补写不可辨内容 |
| confidence | string | 观察可信度 | high / medium / low | 依据图面可辨程度 |
| notes | string | 限制说明 | 标签太小、含义待核验 | 记录证据边界 |

## 数据建模建议

后续若获得高清原图或原始课程资料，可建立以下独立数据表：
- history_periods：历史时期、顺序、起止时间、史料来源；
- schools_geography：流派名称、地域、地理坐标、来源；
- vessel_catalog：花器名称、器型类别、轮廓图、用途；
- stand_catalog：几架／承托器具名称、类型、用途；
- material_taxonomy：花材形态类别、父级类别、子级类别；
- material_examples：花材名称、图像、类别、示例来源；
- arrangement_relations：起点节点、终点节点、关系类型、数量或权重、单位、来源。

## 重要限制
- 图中文字太小的条目不进行猜测性OCR补全。
- 地图颜色与流派名称的对应关系待核验。
- 时间波峰的高度含义待核验。
- 右下曲线宽度是否编码数量／流量待核验。
- 花材、花器的具体名称不从图形外观推断。
