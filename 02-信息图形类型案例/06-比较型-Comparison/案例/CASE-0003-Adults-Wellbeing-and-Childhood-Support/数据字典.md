# 数据字典｜CASE-0003

## 基础数据集.csv

| 字段 | 类型 | 含义 | 单位／口径 | 来源与限制 |
|---|---|---|---|---|
| case_id | string | 案例编号 | CASE-0003 | 本仓库编号 |
| outcome_domain | string | 成年结果领域 | Personal strengths / Social competence | 图面标签 |
| childhood_parental_support | string | 童年父母支持程度 | Very supportive / Less supportive parents | 图面标签 |
| adult_outcome_level | string | 成年结果水平 | High / Low | 图面标签 |
| displayed_percentage | integer | 图面显示百分比 | % | 从用户上传图像逐项转录，未核验原始交叉表 |
| source_sample_size | integer | 图面说明的研究样本量 | 人 | 图面标注1,000名23–24岁受访者；不是各组分母 |
| source_status | string | 数据证据状态 | 文字说明 | 明确标记为图面转录，原始数据未核验 |

## 数据模型
每行对应一个“成年结果领域 × 童年父母支持程度 × 成年结果水平”的组合。两个结果领域各有四个组合，共8行。

## 视觉映射
- 奶油色／浅色区域：HIGH成年结果水平。
- 蓝色区域：LOW成年结果水平。
- Very supportive / Less supportive parents：通过扇区内文字标注区分。
- 圆弧HIGH／LOW标签与笑脸／悲伤表情符号：对成年结果水平进行辅助编码。
- 不将扇区角度或面积视为已验证的百分比比例编码。

## 数据质量说明
- Personal strengths四组图面百分比：27、14、23、38，合计102。
- Social competence四组图面百分比：28、12、21、41，合计102。
- 不做归一化，不推算人数，不把样本总量1,000误作每个组合的已知分母。
- 原始报告取得后，需核对百分比合计、分母、权重、缺失值处理和分组阈值。
