# 编年编目复合型（Hybrid）案例库

本目录收录以同一主题整合多种基础信息逻辑的复合型信息图。Hybrid 是复合结构标签，不替代五大基础数据逻辑；每个案例均需标明主逻辑、辅助逻辑和模块级信息关系。

## 归档原则
不因图面同时出现文字、图标和插画就判定为复合型。必须存在两种或以上真实的信息组织逻辑，并说明各模块的数据关系与相互作用。
