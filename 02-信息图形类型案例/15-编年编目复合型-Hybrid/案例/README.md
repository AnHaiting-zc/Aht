# 编年编目复合型（Hybrid）案例库

本目录收录同一主题中并置多种信息组织逻辑的案例。Hybrid是复合结构标签，不替代五大基础数据逻辑；每个案例均说明主逻辑、辅助逻辑和模块职责。

## 标签说明
- [编年编目复合型定义与判定方法](./00-标签说明.md)

## 案例
- [CASE-0005｜三枝成韵·满室生春：中国插花信息设计](./案例/CASE-0005-Chinese-Flower-Arrangement-Information-Design/README.md)：历史、流派地图、时间脉络、花器与花材分类、关系流线及主题插画组成的多模块复合信息图。
- [CASE-0008｜Quezon City History：奎松市历史与地标编年目录](./案例/CASE-0008-Quezon-City-History-Timeline-Landmark-Catalog/README.md)：十个城市历史／地标条目配年份和图片，中央年份带形成时间轴式外观；年份顺序不连续，底层逻辑以编目为主、编年为辅。\n- [CASE-0010｜Historic Centre of Macao：澳门历史城区编年与遗产地标目录](./案例/CASE-0010-Macau-Historic-Centre-Heritage-Timeline-Catalog/README.md)：左侧历史节点、中央建筑遗产目录、右上区位地图及右侧城市风貌专题构成编年编目复合结构。

## 归档原则
不因画面同时出现插画、文字和照片就判定为复合型。必须存在两种或以上真实的信息组织逻辑，并说明各模块的数据关系与相互作用。
