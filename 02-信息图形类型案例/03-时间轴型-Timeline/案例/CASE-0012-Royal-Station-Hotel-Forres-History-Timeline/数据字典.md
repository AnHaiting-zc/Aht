# 数据字典｜CASE-0012

## 时间节点.csv字段
| 字段 | 含义 |
|---|---|
| event_id | 案例内唯一事件编号 |
| visual_order | 按时间轴阅读顺序整理的节点序号 |
| displayed_date | 图面日期或时期原样转录 |
| event_type | 事件类别 |
| event_title_or_subject | 事件标题或对象 |
| displayed_detail | 图面可辨事件说明 |
| people_or_organizations | 相关人物或组织 |
| amount | 图面金额；无金额留空 |
| currency | 币种 |
| evidence_status | 图面可辨／待核验 |
| ambiguity_note | 识读或口径限制 |

## 视觉模块.csv字段
case_id为案例编号；module_id为模块编号；visual_order为阅读顺序；zone为画面位置；module_content为模块内容；information_role为信息功能；visual_form为视觉形式；visual_encoding为视觉编码；evidence_boundary为识读边界。

## 数据建模建议
时间事件是核心实体。建议补充normalized_start_date、normalized_end_date、date_precision（year／month／day／decade）、event_category、related_asset、source_reference和confidence。人物、组织、建筑影像、广告、地图和物件作为事件关联实体或证据资源。

## 证据等级
- 图面可辨：文字或日期在上传图像中可识读。
- 待核验：姓名拼写、日期、事件关系或历史陈述仍需高清原图或外部档案核对。
- 结构推断：根据版面路径和视觉连接推断的阅读结构，不等同于图面明文。

## 数据边界
1. 1800s按年代范围保存，不转换为单一年份。
2. 约1880年摄影事件不作为精确日级事件。
3. £2,155及2023年约£354,000为图面陈述，折算方法未注明。
4. 1952—1995年交易金额只按图面记录，不视为已核实成交价。
5. 2016收容用途没有明确起止日期。
6. 2019租用与2022取得物业是不同阶段。
7. 事件类别是归档标签，不代表原图具有对应图例。
