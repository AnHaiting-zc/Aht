# 视觉编码与叙事结构｜CASE-0010

## 1. 版式骨架
- 纵向画幅。
- 左侧：历史时间节点纵栏。
- 中央：建筑遗产与历史空间插画目录，是最大视觉主体。
- 右上：历史城区地理位置地图。
- 右侧中下：建筑／街景、关系分支、城市色彩等补充模块。
- 左下：符号图例。
- 通过大量细引线把建筑图像、局部细节与说明文字关联。

## 2. 色彩映射
- 背景：暖米白／象牙白，营造历史文献与档案感。
- 建筑：灰白、砖红、赭橙、亮黄、青绿、蓝绿色。
- 植被：蓝绿色／灰青色。
- 时间线：青绿、橙红、黄色等节点色。
- 地图：浅灰道路底图，橙色区域高亮。
- 城市色彩：离散多列色块。
注意：颜色的视觉功能可以观察，但时间线颜色是否代表事件分类、历史时期或重要程度，需图例核验。

## 3. 图形语法
| 视觉元素 | 图面角色 | 数据／信息角色 |
|---|---|---|
| 时间线竖向路径 | 历史序列骨架 | 编年提示 |
| 彩色圆点与几何节点 | 时间节点 | 节点标识，具体分类语义待核 |
| 建筑立面插画 | 中央主视觉 | 遗产建筑／场所目录 |
| 树木、台阶、围墙、铺地 | 建筑环境 | 场景与空间语境 |
| 引线 | 连接图像与文字 | 注释关联，不代表流程 |
| 右上地图高亮 | 空间强调 | 地理位置提示 |
| 右下分支线 | 结构关系 | 关系语义待核 |
| 色彩竖条 | 颜色样本 | 城市色彩展示，方法待核 |
| 左下图标 | 类别提示 | 图例／符号索引 |

## 4. 建筑插画规范观察
- 建筑正立面是主要表达方式。
- 门窗、柱式、檐口、屋顶、台阶等关键识别特征保留较多细节。
- 采用统一线宽、轮廓和有限色彩，使不同建筑对象视觉一致。
- 以树木、铺地、围墙、道路设施补足场所环境。
- 多组建筑采用编辑性拼接与错位排列，强化目录感。
- 画面不是比例准确的建筑测绘、街区平面或三维模型。

## 5. 信息层级
1. 中英文主标题。
2. 左侧年份／时期。
3. 中央建筑／场所插画。
4. 建筑名称、引线与说明文字。
5. 右侧地图、关系分支与城市色彩专题。
6. 左下图例与来源性小字。

## 6. 可迁移设计规则
1. 历史城区信息图可以采用“时间线＋建筑目录＋区位地图”三核结构。
2. 将建筑作为独立条目，统一插画尺度、视角、描边和细节等级。
3. 每个建筑条目应有名称、位置、年代、类别和来源，缺失字段应明确标记。
4. 时间线节点必须有清晰日期、事件标题和颜色图例。
5. 地图必须标出边界、比例尺、方向和图例。
6. 关系分支图必须说明节点与连线的含义。
7. 城市色彩模块应说明采样对象、采样方法、色值和类别。
8. 引线应避免交叉，并保持标签与对象一一对应。
9. 装饰性建筑场景与真实空间测绘信息要明确区分。
