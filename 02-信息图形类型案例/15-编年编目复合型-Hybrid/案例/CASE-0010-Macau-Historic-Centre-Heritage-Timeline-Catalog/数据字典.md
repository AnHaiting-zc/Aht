# 数据字典｜CASE-0010

## 时间节点.csv
| 字段 | 含义 |
|---|---|
| record_id | 时间节点唯一编号 |
| visual_order | 图面从上至下的视觉顺序 |
| displayed_date_or_period | 图面可辨年份／时期原文 |
| event_text_status | 事件文字的可辨状态 |
| category_marker | 节点颜色、形状等可见形式 |
| location | 图面主题空间 |
| confidence | 转录置信度：高／中／低 |
| notes | 排序、字形或口径说明 |

## 建筑与空间模块.csv
| 字段 | 含义 |
|---|---|
| module_id | 模块唯一编号 |
| visual_order | 画面阅读顺序 |
| region | 模块所在版面区域 |
| module_name | 模块名称 |
| information_role | 信息功能 |
| visual_form | 图形／插画形式 |
| visible_encoding | 可见视觉编码 |
| evidence_status | 可确认程度 |
| notes | 识读限制 |

## 数据边界
1. 年份按图面视觉顺序记录，不自行重新排序。
2. 时间线事件说明字太小无法可靠识读时，不根据澳门历史常识补写。
3. 建筑插画不代表真实建筑比例、面积或地理坐标。
4. 地图高亮色块仅记录为图面空间提示，不推导边界面积。
5. 节点颜色、形状和大小的语义未被完整图例证实时，不能定义为事件类别或重要等级。
6. 右下分支图只记录结构形态，不擅自命名其关系类型。
7. 色彩条只记录为城市色彩模块，不假设其为统计频次或色彩占比。
8. 当前文件为视觉结构转录，不等于经过官方来源核验的澳门历史／遗产数据库。
