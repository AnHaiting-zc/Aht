# 信息图形知识库｜Aht

本仓库建立信息图形研究与设计实践知识库，采用分层目录组织基础数据逻辑、表现形式案例、ISOTYPE、统计图形、Gestalt视觉组织原则及主题设计流程。

## 六个研究模块
1. **01 信息图形数据逻辑**：编年型、层级型、编目型、字母表型、地理型五种基础组织逻辑。
2. **02 信息图形类型案例**：按常见表现形式建立标签、案例索引与分析模板。
3. **03 ISOTYPE信息图**：历史、图符语言、案例研究与设计实践。
4. **04 统计图形分析**：数据结构、统计方法、图表选择与视觉编码。
5. **05 Gestalt视觉组织原则**：视觉分组、连续、闭合、图底关系等原则。
6. **06 主题信息图形设计**：从调研、数据整理到叙事、视觉编码和最终交付的流程。

## 五维研究框架
每种基础数据逻辑均从 A 基本数据逻辑、B 统计图形与计算、C 视觉编码、D 数据/信息架构、E 视觉叙事架构五个维度展开。

## 案例规范
新增案例应记录原图来源、可核验事实、数据字段、推导过程及不确定性。第三方作品应遵守版权许可，优先保存来源链接，不未经许可复制原图或他人完整文稿。此仓库中的空白文件为待研究模板，请逐步补充独立分析。
