# 数据字典｜CASE-0006

## 1. 流程步骤表（steps.csv）

| 字段 | 类型 | 含义 |
|---|---|---|
| case_id | string | 案例编号 |
| step_no | integer | 原图步骤编号，保留原始顺序 |
| step_title_vi | string | 越南语步骤标题；原图未单列时留空 |
| operation_zh | string | 步骤操作的中文释义 |
| ingredients | string | 涉及食材，多个值以分号分隔 |
| tools_or_objects | string | 图面出现的器具或对象 |
| output_or_state | string | 步骤产生的中间状态或结果 |
| sequence_role | string | 流程中的步骤角色 |
| confidence | string | 图像辨识可信度 |
| notes | string | 工序依赖或翻译待核验事项 |

## 2. 食材表（ingredients.csv）

| 字段 | 类型 | 含义 |
|---|---|---|
| case_id | string | 案例编号 |
| ingredient_vi | string | 越南语原始食材名称 |
| ingredient_zh | string | 中文释义 |
| listed_in_bottom_legend | boolean | 是否出现在底部图例 |
| mentioned_in_steps_or_intro | boolean | 是否在正文或步骤中提及 |
| category | string | 食材在菜品中的角色 |
| confidence | string | 识别可信度 |
| notes | string | 翻译与语境限制 |

## 3. 关系建模建议
- recipe 1:N steps；
- recipe 1:N ingredients；
- steps N:M ingredients；
- steps N:M tools；
- steps 产生 intermediate_preparations；
- 最后一步产生 final_dish。

## 4. 数据边界
- 不填入图面未提供的重量、份数、温度、火力或额外时间。
- 仅“至少3小时”被图面明确提及。
- 底部七项食材图例不等于完整配料表；正文额外提到米粉、鲜葱、炸葱和多种越式肉制品。
- 保留越南语原词，避免中文译名掩盖品类差异。
